Tutorial para Prestação de Contas do Atleta

Siga o passo a passo para enviar sua frequência bimestral

  1. Acesse o sistema Clique em “Sistema de Acompanhamento do Atleta” ou escaneie o QR Code disponível no final desta página.
  2. Faça login Informe os dados solicitados: CPF e data de nascimento.
  3. Abra o menu lateral Dentro do sistema, procure o ícone ≡ no menu lateral.
  4. Acesse a opção ➡️ Frequência Bimestral.
  5. Clique em NOVO.
  6. Selecione o período Escolha o bimestre/período correspondente.
  7. Informe a frequência Preencha a frequência dos atletas conforme os treinos realizados.
  8. Preencha também O sistema solicita informações sobre:
    • participação em competições;
    • fotos e/ou vídeos dos treinos;
    • fotos e/ou vídeos de competições, quando houver.
  9. Confira tudo Revise todas as informações antes de enviar.
  10. Envie/salve Clique para enviar/salvar a frequência.
  11. Acompanhe o status Depois, a própria tela “Frequências enviadas” permite acompanhar o status do envio.

Acesse agora
